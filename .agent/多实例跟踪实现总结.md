## 🔧 Bug修复

### Bug 1: 索引越界（已修复）
**问题**：在 `UpdateInstanceTracker` 中移除实例时，使用 `std::distance` 计算索引会在 `erase` 后失效。

**修复**：改用独立的索引变量 `idx`，在 `erase` 后不增加索引。

```cpp
// 修复前（错误）
for (auto it = mTrackedInstances.begin(); it != mTrackedInstances.end(); ) {
    size_t idx = std::distance(mTrackedInstances.begin(), it);  // ❌ erase后失效
    ...
}

// 修复后（正确）
auto it = mTrackedInstances.begin();
size_t idx = 0;
while (it != mTrackedInstances.end()) {
    if (idx < trackedMatched.size() && !trackedMatched[idx]) {
        ...
        if (需要删除) {
            it = mTrackedInstances.erase(it);
            continue;  // ✅ 不增加idx
        }
    }
    ++it;
    ++idx;
}
```

### Bug 2: globalIDs越界（已修复）

## 🎯 工作原理

### 实例跟踪流程

```
帧 t:
  1. YOLO检测 → [椅子@(100,200), 椅子@(500,200)]
  2. 收集候选物体 → candidateBboxes, candidateClassNames
  3. UpdateInstanceTracker:
     - 第一次见到 → 创建新实例 ID=1, ID=2
     - 返回 globalIDs = [1, 2]
  4. 生成mInstanceMap:
     - 左边区域 = 1
     - 右边区域 = 2

帧 t+1: (椅子B移动)
  1. YOLO检测 → [椅子@(100,200), 椅子@(520,200)]
  2. UpdateInstanceTracker:
     - IoU匹配:
       * (100,200) vs ID=1的bbox → IoU=0.95 ✅ 匹配
       * (520,200) vs ID=2的bbox → IoU=0.85 ✅ 匹配
     - 返回 globalIDs = [1, 2]  ← ID保持不变！
  3. 生成mInstanceMap:
     - 左边区域 = 1 (稳定)
     - 右边区域 = 2 (稳定)

帧 t+2: (椅子B被遮挡)
  1. YOLO检测 → [椅子@(100,200)]
  2. UpdateInstanceTracker:
     - ID=1 匹配成功
     - ID=2 未匹配 → framesSinceLastSeen = 1
     - 返回 globalIDs = [1]
  3. 生成mInstanceMap:
     - 左边区域 = 1

帧 t+3-t+31: (椅子B持续遮挡)
  - ID=2 的 framesSinceLastSeen 递增
  - 达到30帧后删除ID=2

帧 t+32: (椅子B重新出现)
  1. YOLO检测 → [椅子@(100,200), 椅子@(540,200)]
  2. UpdateInstanceTracker:
     - (100,200) → ID=1 (匹配)
     - (540,200) → 新实例 ID=3 (ID=2已被删除)
```

## 🚀 下一步：修改Tracking.cc

当前代码已经为每个MapPoint分配了稳定的实例ID，但Tracking.cc中的动态性检查逻辑还没有修改。

### 需要实现的功能

```cpp
// Tracking.cc - 按实例ID分组检查
std::map<int, std::vector<MapPoint*>> instanceMapPoints;

for (int i = 0; i < mCurrentFrame.N; i++) {
    MapPoint* pMP = mCurrentFrame.mvpMapPoints[i];
    if (!pMP || pMP->isBad()) continue;
    
    // 只处理半动态物体
    if (pMP->mInstanceID > 0 && pMP->mInstanceID < 250) {
        instanceMapPoints[pMP->mInstanceID].push_back(pMP);
    }
}

// 对每个实例独立判定
for (auto const& [instanceID, mapPoints] : instanceMapPoints) {
    int dynamicCount = 0;
    int totalCount = mapPoints.size();
    
    for (MapPoint* pMP : mapPoints) {
        bool isDynamic = CheckMapPointDynamic(pMP, mCurrentFrame);
        if (isDynamic) {
            pMP->mDynamicVotes++;
            dynamicCount++;
        } else {
            pMP->mDynamicVotes = max(0, pMP->mDynamicVotes - 1);
        }
    }
    
    // 如果该实例的大部分点都是动态的
    if (dynamicCount > totalCount * 0.5 && totalCount > 5) {
        for (MapPoint* pMP : mapPoints) {
            if (pMP->mDynamicVotes >= 3) {
                pMP->SetBadFlag();
            }
        }
        cout << "[Dyna-Logic] Instance " << instanceID 
             << " is DYNAMIC (" << dynamicCount << "/" << totalCount << ")" << endl;
    }
}
```
