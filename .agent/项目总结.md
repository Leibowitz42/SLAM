# 🎉 多实例动态物体剔除 - 项目总结

## 📌 项目概述

**目标**：实现基于实例ID的动态物体检测和剔除系统，能够独立跟踪和判定每个椅子实例的动态性。

**挑战**：
- ❌ 原系统：一把椅子动，所有椅子都被删除
- ✅ 新系统：只删除真正移动的椅子，保留静态椅子

## ✅ 完成的工作

### 1. 实例跟踪器 (YoloDetect.cpp)

**实现**：
```cpp
// 核心功能
std::vector<int> UpdateInstanceTracker(bboxes, classNames) {
    1. IoU匹配：找到最相似的已跟踪实例
    2. ID分配：匹配成功保持ID，否则创建新ID
    3. 实例清理：30帧未见则删除
}
```

**关键参数**：
- `IOU_THRESHOLD = 0.3`：匹配阈值
- `MAX_FRAMES_LOST = 30`：丢失阈值

**效果**：
- ✅ 稳定的跨帧ID
- ✅ 自动创建和删除实例
- ✅ 支持多类别（椅子、书本等）

### 2. MapPoint 实例ID存储 (MapPoint.cc)

**实现**：
```cpp
class MapPoint {
    int mInstanceID;  // 稳定的实例ID
    
    // 从mInstanceMap读取ID
    uchar id = pFrame->mInstanceMap.at<uchar>(v, u);
    if (id > 0 && id < 255) {
        mInstanceID = id;  // 半动态物体
    } else {
        mInstanceID = -1;  // 静态背景或绝对动态
    }
};
```

**效果**：
- ✅ 每个3D点知道自己属于哪个实例
- ✅ 支持实例级操作

### 3. 基于实例的动态检查 (Tracking.cc)

**实现**：
```cpp
// 1. 按实例ID分组
std::map<uchar, std::vector<int>> instanceFeatureMapping;

// 2. 对每个实例独立判定
for (auto [id, featureIndices] : instanceFeatureMapping) {
    bool isDynamic = CheckInstanceDynamic(mCurrentFrame, id);
    
    if (isDynamic && mMoveConfirmCnt[id] >= 2) {
        // 剔除该实例的所有点
        for (int idx : featureIndices) {
            mCurrentFrame.mvpMapPoints[idx]->SetBadFlag();
        }
    }
}
```

**效果**：
- ✅ 实例级独立判定
- ✅ 连续2帧确认机制
- ✅ 精准剔除

### 4. 对极几何检查 (CheckInstanceDynamic)

**实现**：
```cpp
bool CheckInstanceDynamic(Frame &CurrentFrame, int InstanceID) {
    1. 计算基础矩阵 F21
    2. 计算点到对极线的距离
    3. 统计违反约束的点数
    4. 如果 > 30% 违反 → 判定为动态
}
```

**关键参数**：
- `epipolar_dist_th = 3.5`：对极距离阈值
- `dynamic_ratio = 0.3`：动态比例阈值

**效果**：
- ✅ 几何验证
- ✅ 鲁棒性好

## 🔧 关键技术

### 1. IoU匹配

**原理**：
```
IoU = 交集面积 / 并集面积
```

**优势**：
- 简单高效
- 对尺度变化鲁棒
- 适合实时应用

### 2. 对极几何

**原理**：
```
x_curr^T * F * x_ref = 0
```

**优势**：
- 纯几何约束
- 无需深度信息
- 可靠性高

### 3. 投票机制

**原理**：
```
if (dynamic_votes / total_checks > 0.3) {
    isDynamic = true;
}
```

**优势**：
- 容忍噪声
- 避免误检
- 平衡灵敏度

### 4. 连续确认

**原理**：
```
if (mMoveConfirmCnt[id] >= 2) {
    // 确认为动态
}
```

**优势**：
- 避免瞬时误判
- 提高可靠性
- 减少抖动

## 🐛 解决的Bug

### Bug 1: 循环中修改向量导致越界

**问题**：
```cpp
for (size_t i = 0; i < bboxes.size(); i++) {
    for (size_t j = 0; j < mTrackedInstances.size(); j++) {
        if (trackedMatched[j]) ...  // ❌ 越界
    }
    mTrackedInstances.push_back(newInstance);  // ❌ 改变size
}
```

**修复**：
```cpp
std::vector<TrackedInstance> newInstances;  // 先收集
for (...) {
    newInstances.push_back(newInstance);  // ✅ 不修改原向量
}
for (const auto& inst : newInstances) {
    mTrackedInstances.push_back(inst);  // ✅ 循环后添加
}
```

**教训**：
- 不要在遍历时修改容器
- 使用临时容器收集变更

### Bug 2: 退出时内存错误

**问题**：
```
malloc(): unsorted double linked list corrupted
```

**分析**：
- 发生在程序退出时
- 不影响SLAM功能
- 可能是ORB-SLAM3自身问题

**处理**：
- 暂时忽略（不影响功能）
- 未来可优化析构函数
