### 1. 实例跟踪器 (YoloDetect.cpp)

**功能**：为每个检测到的物体分配稳定的全局ID

**实现**：
```cpp
// 核心数据结构
struct TrackedInstance {
    int globalID;              // 稳定的全局ID
    cv::Rect2f bbox;          // 边界框
    std::string className;     // 类别名称
    int framesSinceLastSeen;   // 未见帧数
};

// 跟踪逻辑
std::vector<int> UpdateInstanceTracker(bboxes, classNames) {
    1. 对每个新检测，计算与已跟踪实例的IoU
    2. IoU > 0.3 → 匹配成功，更新实例
    3. IoU < 0.3 → 创建新实例，分配新ID
    4. 超过30帧未见 → 删除实例
}
```

**关键参数**：
- `IOU_THRESHOLD = 0.3`：IoU匹配阈值
- `MAX_FRAMES_LOST = 30`：最大丢失帧数

**输出**：
```
[Instance Tracker] New instance: ID=1, class=chair
[Instance Tracker] New instance: ID=32, class=chair
[Instance Tracker] Lost: ID=31, class=chair
```

### 2. MapPoint 实例ID存储 (MapPoint.cc)

**功能**：每个3D点存储其所属实例的稳定ID

**实现**：
```cpp
class MapPoint {
    int mInstanceID;  // 稳定的实例ID
    
    // 构造函数中初始化
    MapPoint(Pos, pFrame, idxF) {
        uchar id = pFrame->mInstanceMap.at<uchar>(v, u);
        if (id > 0 && id < 255) {
            mSemanticLabel = id;
            mInstanceID = id;  // 存储稳定ID
        } else {
            mInstanceID = -1;  // 静态背景或绝对动态
        }
    }
};
```

**ID含义**：
- `mInstanceID = -1`：静态背景或绝对动态物体
- `mInstanceID > 0`：半动态物体的稳定实例ID

### 3. 基于实例的动态检查 (Tracking.cc)

**功能**：对每个实例独立进行对极几何检查

**实现流程**：
```cpp
// 1. 按实例ID分组特征点
std::map<uchar, std::vector<int>> instanceFeatureMapping;
for (特征点 i) {
    uchar id = mInstanceMap.at<uchar>(v, u);
    if (id > 0 && id < 255) {
        instanceFeatureMapping[id].push_back(i);
    }
}

// 2. 对每个实例独立判定
for (auto [id, featureIndices] : instanceFeatureMapping) {
    bool isDynamic = CheckInstanceDynamic(mCurrentFrame, id);
    
    if (isDynamic) {
        mMoveConfirmCnt[id]++;
    } else {
        mMoveConfirmCnt[id] = 0;
    }
    
    // 3. 连续2帧判定为动态 → 剔除该实例的所有点
    if (mMoveConfirmCnt[id] >= 2) {
        for (int idx : featureIndices) {
            mCurrentFrame.mvbOutlier[idx] = true;
            mCurrentFrame.mvpMapPoints[idx]->SetBadFlag();
        }
        cout << "[Dyna-Logic] Instance ID " << id 
             << " is DYNAMIC. Removed " << featureIndices.size() 
             << " points." << endl;
    }
}
```

### 4. 对极几何检查 (CheckInstanceDynamic)

**功能**：使用对极约束判断物体是否移动

**原理**：
- 静态物体：满足对极约束 `x_curr^T * F * x_ref = 0`
- 动态物体：违反对极约束（点到对极线距离大）

**实现**：
```cpp
bool CheckInstanceDynamic(Frame &CurrentFrame, int InstanceID) {
    1. 计算基础矩阵 F21 (从参考帧到当前帧)
    2. 遍历属于该实例的所有特征点
    3. 计算每个点到对极线的距离
    4. 统计违反约束的点数
    5. 如果 > 30% 的点违反约束 → 判定为动态
}
```

**关键参数**：
- `epipolar_dist_th = 3.5`：对极距离阈值（像素）
- `动态比例阈值 = 0.3`：30%的点违反约束即判定为动态
- `最小检查点数 = 3`：至少需要3个点才能判定

**问题**：
```cpp
for (size_t i = 0; i < bboxes.size(); i++) {
    for (size_t j = 0; j < mTrackedInstances.size(); j++) {
        if (trackedMatched[j]) ...  // ❌ 越界！
    }
    if (未匹配) {
        mTrackedInstances.push_back(newInstance);  // ❌ 改变了size
    }
}
```

**修复**：
```cpp
std::vector<TrackedInstance> newInstances;  // 先收集

for (size_t i = 0; i < bboxes.size(); i++) {
    if (未匹配) {
        newInstances.push_back(newInstance);  // ✅ 不修改原向量
    }
}

// 循环结束后统一添加
for (const auto& inst : newInstances) {
    mTrackedInstances.push_back(inst);
}
```

## 📊 工作流程

### 完整的数据流

```
帧N: RGB图像
  ↓
YOLOv8检测
  ↓
检测结果: [bbox1, bbox2, ...]
  ↓
UpdateInstanceTracker (IoU匹配)
  ↓
稳定ID: [1, 32, 33, ...]
  ↓
mInstanceMap (每个像素存储实例ID)
  ↓
MapPoint创建 (从mInstanceMap读取ID)
  ↓
MapPoint.mInstanceID = 稳定ID
  ↓
Tracking.cc (按实例ID分组)
  ↓
CheckInstanceDynamic (对极几何检查)
  ↓
动态判定 → 剔除该实例的所有MapPoint
```

### 实例生命周期

```
帧1: 检测到椅子A → 创建ID=1
帧2: 椅子A仍在 → 匹配成功，ID=1
帧3: 椅子A移动 → ID=1，但位置变化
      ↓ 对极几何检查
      ↓ 违反约束 > 30%
      ↓ 判定为动态
      ↓ 剔除ID=1的所有点
帧4: 椅子B出现 → 创建ID=32
      椅子A消失 → framesSinceLastSeen++
帧34: 椅子A未见30帧 → 删除ID=1
```
