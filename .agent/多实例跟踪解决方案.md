# 多实例椅子跟踪问题与解决方案

## 🎯 问题场景

```
房间里有两把椅子：
┌─────────┐          ┌─────────┐
│ 椅子A   │          │ 椅子B   │
│ (静止)  │          │ (移动)  │
└─────────┘          └─────────┘
```

**挑战**：
- 两把椅子的语义类别相同（都是"chair"）
- 需要区分是哪一把椅子在动
- 不能因为椅子B动了就删除椅子A的点

## ❌ 当前方案的问题

### 问题1：每帧重新分配ID
```cpp
// YoloDetect.cpp
int candidateID = 1;  // ❌ 每帧都从1开始
for (int i = 0; i < result.size(); i++) {
    mInstanceMap(result[i].box).setTo(cv::Scalar(candidateID), result[i].boxMask);
    candidateID++;
}
```

**结果**：
```
帧1: 左边椅子=ID1, 右边椅子=ID2
帧2: 右边椅子=ID1, 左边椅子=ID2  ← ID交换了！
```

### 问题2：MapPoint只存储语义类别
```cpp
// MapPoint.h
uchar mSemanticLabel;  // ❌ 只知道"是椅子"，不知道"是哪把椅子"
```

## ✅ 解决方案：稳定的实例跟踪

### 核心思想

**建立跨帧的实例ID映射**：通过 Bounding Box 的位置和大小匹配，为同一物体分配稳定的全局ID。

### 实现方案

#### 步骤1：在 YoloDetection 中添加实例跟踪器

```cpp
// YoloDetect.h
class YoloDetection {
private:
    // 实例跟踪器：存储上一帧的检测结果
    struct TrackedInstance {
        int globalID;           // 全局唯一ID
        cv::Rect2f bbox;        // 边界框
        std::string className;  // 类别名称
        int framesSinceLastSeen; // 未见到的帧数
    };
    
    std::vector<TrackedInstance> mTrackedInstances;
    int mNextGlobalID = 1;  // 全局ID计数器
    
    // 匹配函数：计算两个bbox的IoU
    float ComputeIoU(const cv::Rect2f& box1, const cv::Rect2f& box2);
    
    // 更新跟踪器
    void UpdateInstanceTracker(const std::vector<OutputParams>& detections);
};
```

#### 步骤2：实现IoU匹配

```cpp
// YoloDetect.cpp
float YoloDetection::ComputeIoU(const cv::Rect2f& box1, const cv::Rect2f& box2) {
    float x1 = std::max(box1.x, box2.x);
    float y1 = std::max(box1.y, box2.y);
    float x2 = std::min(box1.x + box1.width, box2.x + box2.width);
    float y2 = std::min(box1.y + box1.height, box2.y + box2.height);
    
    float intersection = std::max(0.0f, x2 - x1) * std::max(0.0f, y2 - y1);
    float union_area = box1.area() + box2.area() - intersection;
    
    return intersection / (union_area + 1e-6);
}

void YoloDetection::UpdateInstanceTracker(const std::vector<OutputParams>& detections) {
    // 1. 标记所有已跟踪实例为"未匹配"
    std::vector<bool> matched(mTrackedInstances.size(), false);
    std::vector<int> detectionToGlobalID(detections.size(), -1);
    
    // 2. 对每个新检测，找到最佳匹配的已跟踪实例
    for (int i = 0; i < detections.size(); i++) {
        if (!count(mvCandidateNames.begin(), mvCandidateNames.end(), 
                   model._className[detections[i].id])) {
            continue;  // 只跟踪半动态物体
        }
        
        cv::Rect2f newBox = detections[i].box;
        std::string className = model._className[detections[i].id];
        
        float bestIoU = 0.3f;  // IoU阈值
        int bestMatchIdx = -1;
        
        // 在已跟踪实例中寻找最佳匹配
        for (int j = 0; j < mTrackedInstances.size(); j++) {
            if (matched[j]) continue;  // 已被匹配
            if (mTrackedInstances[j].className != className) continue;  // 类别不同
            
            float iou = ComputeIoU(newBox, mTrackedInstances[j].bbox);
            if (iou > bestIoU) {
                bestIoU = iou;
                bestMatchIdx = j;
            }
        }
        
        if (bestMatchIdx >= 0) {
            // 找到匹配：更新已有实例
            matched[bestMatchIdx] = true;
            mTrackedInstances[bestMatchIdx].bbox = newBox;
            mTrackedInstances[bestMatchIdx].framesSinceLastSeen = 0;
            detectionToGlobalID[i] = mTrackedInstances[bestMatchIdx].globalID;
        } else {
            // 未找到匹配：创建新实例
            TrackedInstance newInstance;
            newInstance.globalID = mNextGlobalID++;
            newInstance.bbox = newBox;
            newInstance.className = className;
            newInstance.framesSinceLastSeen = 0;
            
            mTrackedInstances.push_back(newInstance);
            detectionToGlobalID[i] = newInstance.globalID;
        }
    }
    
    // 3. 移除长时间未见到的实例（超过30帧）
    for (auto it = mTrackedInstances.begin(); it != mTrackedInstances.end(); ) {
        if (!matched[std::distance(mTrackedInstances.begin(), it)]) {
            it->framesSinceLastSeen++;
            if (it->framesSinceLastSeen > 30) {
                it = mTrackedInstances.erase(it);
                continue;
            }
        }
        ++it;
    }
    
    return detectionToGlobalID;
}
```

bool YoloDetection::Detect() {
    // ... 前面的代码 ...

        mInstanceMap.setTo(0);

            // ... 可视化代码 ...
            
            // 使用稳定的全局ID而不是临时ID
            if (count(mvCandidateNames.begin(), mvCandidateNames.end(), 
                     model._className[result[i].id])) {
                
                int stableID = globalIDs[i];
                if (stableID > 0 && stableID < 250) {
                    mInstanceMap(result[i].box).setTo(cv::Scalar(stableID), 
                                                     result[i].boxMask);
                }
            }
            else if (count(mvDynamicNames.begin(), mvDynamicNames.end(),

                mInstanceMap(result[i].box).setTo(cv::Scalar(255), result[i].boxMask);
            }
        }
    }
    return true;
}

#### 步骤4：MapPoint 存储稳定的实例ID

```cpp
// MapPoint.h
class MapPoint {
public:
    uchar mSemanticLabel;      // 语义类别 (0=静态, 1-249=半动态, 255=绝对动态)
    int mInstanceID;           // ✅ 新增：稳定的实例ID（全局唯一）
    int mDynamicVotes;         // 动态性投票
};

// MapPoint.cc - 初始化
MapPoint::MapPoint(const Eigen::Vector3f &Pos, Map* pMap, Frame* pFrame, const int &idxF) {
    // ... 其他代码 ...
    
    mSemanticLabel = 0;
    mInstanceID = -1;  // -1表示未分配
    mDynamicVotes = 0;
    
    if(!pFrame->mInstanceMap.empty()) {
        int u = cvRound(pFrame->mvKeys[idxF].pt.x);
        int v = cvRound(pFrame->mvKeys[idxF].pt.y);
        
        if(边界检查) {
            uchar id = pFrame->mInstanceMap.at<uchar>(v, u);
            
            if(id > 0 && id < 255) {
                mSemanticLabel = id;  // 半动态物体
                mInstanceID = id;     // ✅ 存储稳定的实例ID
            } else if(id == 255) {
                mSemanticLabel = 255; // 绝对动态
                mInstanceID = -1;
            } else {
                mSemanticLabel = 0;   // 静态背景
                mInstanceID = -1;
            }
        }
    }
}
```

#### 步骤5：修改动态性检查逻辑

```cpp
// Tracking.cc
// 按实例ID分组 MapPoint
std::map<int, std::vector<MapPoint*>> instanceMapPoints;

for(int i=0; i<mCurrentFrame.N; i++) {
    MapPoint* pMP = mCurrentFrame.mvpMapPoints[i];
    if(!pMP || pMP->isBad()) continue;
    
    // 只处理半动态物体
    if(pMP->mSemanticLabel > 0 && pMP->mSemanticLabel < 255) {
        int instanceID = pMP->mInstanceID;
        if(instanceID > 0) {
            instanceMapPoints[instanceID].push_back(pMP);
        }
    }
}

// 对每个实例独立判定
for(auto const& [instanceID, mapPoints] : instanceMapPoints) {
    int dynamicCount = 0;
    int totalCount = 0;
    
    for(MapPoint* pMP : mapPoints) {
        bool isDynamic = CheckMapPointDynamic(pMP, mCurrentFrame);
        if(isDynamic) {
            pMP->mDynamicVotes++;
            dynamicCount++;
        } else {
            pMP->mDynamicVotes = max(0, pMP->mDynamicVotes - 1);
        }
        totalCount++;
    }
    
    // 如果该实例的大部分点都是动态的，删除所有点
    if(dynamicCount > totalCount * 0.5 && totalCount > 5) {
        for(MapPoint* pMP : mapPoints) {
            if(pMP->mDynamicVotes >= 3) {
                pMP->SetBadFlag();
            }
        }
        cout << "[Dyna-Logic] Instance " << instanceID 
             << " is DYNAMIC (" << dynamicCount << "/" << totalCount << " points)" << endl;
    }
}
```

## 🎯 工作流程示例

### 场景：两把椅子，一把动一把不动

```
帧1:
  YOLO检测: [椅子@(100,200), 椅子@(500,200)]
  实例跟踪: 椅子A=ID1, 椅子B=ID2
  mInstanceMap: 左边区域=1, 右边区域=2
  MapPoint创建: 
    - 左边的点: mInstanceID=1
    - 右边的点: mInstanceID=2

帧2: (椅子B移动到(520,200))
  YOLO检测: [椅子@(100,200), 椅子@(520,200)]
  实例跟踪: 
    - (100,200) 匹配 椅子A → ID1 (IoU=0.95)
    - (520,200) 匹配 椅子B → ID2 (IoU=0.85)
  对极约束检查:
    - Instance 1: 0/50 点违反约束 → 静止 ✅
    - Instance 2: 45/50 点违反约束 → 动态 ❌
  结果: 只删除 Instance 2 的 MapPoint

帧3: (椅子B被遮挡)
  YOLO检测: [椅子@(100,200)]
  实例跟踪: 
    - 椅子A=ID1 (匹配)
    - 椅子B=ID2 (framesSinceLastSeen=1)
  
帧4: (椅子B重新出现)
  YOLO检测: [椅子@(100,200), 椅子@(540,200)]
  实例跟踪:
    - (100,200) → ID1
    - (540,200) 匹配 椅子B → ID2 (IoU=0.7) ✅ ID保持不变！
```

## 📊 优势

| 特性 | 旧方案 | 新方案 |
|------|--------|--------|
| **区分多个实例** | ❌ 无法区分 | ✅ 每个实例独立ID |
| **抗遮挡** | ❌ ID重置 | ✅ 基于IoU匹配 |
| **精确删除** | ❌ 可能误删 | ✅ 只删除动态实例 |
| **跨帧稳定性** | ❌ 每帧重新分配 | ✅ 全局ID保持 |

## ⚠️ 注意事项

1. **IoU阈值调优**：0.3可能需要根据实际情况调整
2. **遮挡处理**：`framesSinceLastSeen > 30` 的阈值需要测试
3. **ID溢出**：全局ID可能会很大，考虑使用 `int` 而不是 `uchar`
4. **性能开销**：每帧需要计算IoU矩阵，复杂度 O(n²)

## 💡 核心洞察

> **问题的本质是：需要实例级别的身份识别，而不仅仅是语义类别。**
> 
> 通过 Bounding Box 的 IoU 匹配，可以在没有专门跟踪器的情况下，实现简单但有效的多实例跟踪。
