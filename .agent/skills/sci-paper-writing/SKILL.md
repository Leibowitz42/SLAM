# 技能指南：SCI 级学术论文写作与润色 (SCI Paper Writing)

本技能定义了当用户要求**撰写、重写或润色学术论文**（包括但不限于摘要、引言、相关工作、架构描述、实验分析等）时，我必须遵循的“脱胎换骨级”排版与语言规则。该技能在工科（SLAM、机器人、深度学习、边缘计算等方向）尤为受用。

## 1. 核心排版规范：无缝衔接的大段落
- **取消细碎和突兀的子级标题**：真正的顶刊 SCI 论文在主干章节（如 Introduction, Related Work）内，极少使用点状的 `1.1`、`1.2` 等深层子标题。全文应依靠逻辑严密的重磅主题句（Topic Sentence）将各段落紧紧交织在一起。
- **杜绝口语化 Markdown 列表**：在表述“主要贡献（Contributions）”、“实验配置”或“对比优势”时，绝对禁止使用 `- ` 或 `* ` 这种散装的无序列表。所有的枚举都应当以“首先，...；其次，...；最后，...”这种严密的连续长段落格式无缝糅合到篇幅中。

## 2. 语言调性：严谨、客观、标准的 SCI 学术规范
- **绝对禁止夸大与主观词汇**：这是核心红线！在任何时候都**不能使用**网络化、夸张或者情感浓烈的词汇，如：“脱胎换骨”、“降维打击”、“惊险级逆转”、“逆天”、“统治级”、“暴力收缩”、“碾压”等。这些词语严重违背了 SCI 论文的客观公正原则。
- **平实而精准的技术陈述**：科研突破必须依靠事实和数据来表现，而不是修辞手法。
  - 差的示范（夸张）：”斩获了断崖式的精度跃升“、”达成了极其暴力的耗时收缩“、”脱胎换骨级的重设“。
  - **标准的示范（学术）**：”显著降低了绝对轨迹漂移误差“、”实现了计算冗余的有效消减“、”执行了深度的底层架构重写“。
- **严谨的衔接与过渡**：运用符合国际学术期刊审美的平实质朴的衔接词，例如“此外”、“进一步地”、“相较于基线方法”、“值得注意的是”、“实测数据表明”，保持全篇论述的客观与克制。

## 3. 面向底层的概念挖掘 (Deep Hardware-Aware)
对于需要强调工程价值的系统级论文，必须让读者明确体会到作者对于软硬架构的深入理解，但同样要保持克制：
- **算法篇**：使用标准的数学与计算机视觉术语（如：“基础矩阵的对极约束校验”、“先验掩码覆盖层”、“重投影误差最小化”）。
- **硬件与编译篇**：精准描述底层通讯机制，不带感情色彩（如：“采用了算子融合（Kernel Fusion）技术”、“引入 FP16 半精度量化”、“利用零拷贝（Zero-copy）机制优化了由内存屏障造成的通讯延迟”）。

## 4. 使用要求
当你检测到用户在写 SCI 或高水平学术推导文体并要求修改时，调用本套风格准则进行重构。产出的文字必须是**“完全客观、逻辑致密、没有任何文学渲染的专业工程陈述”**。
