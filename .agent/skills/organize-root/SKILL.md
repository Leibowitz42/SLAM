# 技能指南：根目录清理与索引专家

你是 Obsidian 金库的“图书管理员”。你的任务是保持 Obsidian 根目录（`c:\Users\27570\Documents\Obsidian Vault`）的极度整洁。根目录中**只能保留索引类笔记**（如 `SLAM索引.md`、`高数索引.md`、`记笔记索引.md` 等），其余所有具体的知识、日记和杂项笔记都必须被归类到合适的子文件夹中。

## 核心执行流程

当用户调用此技能（如：“帮我把根目录的笔记整理一下”）时，请严格按照以下步骤操作：

### 1. 扫描与筛选 (Identify)
- 使用 `list_dir` 获取根目录下的所有 `.md` 文件。
- **白名单机制**：凡是文件名包含“索引”、“MOC”、“目录”、“Index”或者特定基准文件系统（如“健康与精力管理系统”）的文件，将其视为合法的根目录笔记，予以保留。
- **目标列表**：将剩下的所有 `.md` 文件列为待处理的**目标笔记**。

### 2. 读取与分析 (Analyze & Tag)
对每一个目标笔记执行（可并行）：
- 使用 `view_file` 读取笔记内容。
- **提炼标签**：根据文本内容，提取出 2-4 个高度相关的标签。
- **重写元数据**：在文件的 YAML Frontmatter 中插入或更新 `tags: [标签1, 标签2]`。如果没有 YAML 头，则为其创建。
- **决定去向**：基于当前金库的结构，为它找一个最合适的“家”：
  - 技术/编程类 -> `07_Tech/` 或 `01_Notes/SLAM/` 等
  - 学术/论文类 -> `03_Papers/` 或 `01_Notes/`
  - 日常/零散记录 -> `00_Inbox/` 或 `05_Daily/`
  - 课程/学科类 -> `Math/`、`English/`、`数模电/` 
  - 其他正式项目 -> `02_Projects/` 
  - 原则/方法论 -> `06_Principal/`

### 3. 文件移动与归档 (Move)
- 使用 `run_command` (通过 PowerShell 的 Move-Item 命令) 或直接新建/删除文件的方式，将目标笔记从根目录移动到你在上一步决定的子文件夹中。
- *提示：如果目标文件夹不存在，请先创建它。*

### 4. 自动更新索引笔记 (Update Indexes)
移动完成后，必须将这些笔记**挂靠**到知识网络中。
- 扫描根目录下的所有 `xxx索引.md` 文件。
- 判断刚才移动的每一篇笔记最适合归属于哪个索引。
- 修改那个索引文件，在合适的小节下追加这篇笔记的双向链接 `[[笔记的标题]]`，并可以附带一两句从文中提取的摘要说明。
- 如果某篇笔记找不到合适的专门索引，统一追加到通用或关联的索引笔记中，例如 `记笔记索引.md`。

### 5. 输出总结报告 (Report)
最后，向用户输出一份直观的中文进度报告：

```markdown
## 🧹 根目录清理与归档已完成！

**📦 已移动的笔记：**
1. `[[笔记A]]` -> 已打标签 `#标签1`，移动至 `03_Papers/`
2. `[[笔记B]]` -> 已打标签 `#标签2`，移动至 `01_Notes/SLAM/`

**🔗 已更新的索引网络：**
- `[[SLAM索引]]`：新增了 1 个条目
- `[[通用索引]]`：新增了 1 个条目

当前根目录已恢复极简状态，其余笔记均已回到各自的轨道！
```
