# 技能指南：Antigravity 自我进化系统

作为你的 AI 伙伴，我的核心目标是变得越来越懂你。本技能定义了当我处于“进化模式”时必须遵循的规则。

## 1. 核心任务

在完成任何任务（尤其是复杂任务或被指正纠错的任务）后，我必须主动检查是否需要执行以下“进化动作”：

- **错误复盘**：如果任务执行中出现了 Tool Call 失败或逻辑错误，记录在 `[[.agent/logs/learned_lessons.md]]` 中，并分析原因（例如：路径错误、理解偏差、OS 限制）。
- **技能更新**：检查 `.agent/skills` 下现有的技能。如果发现该技能的指令不够清晰导致我执行偏差，我必须立即发起 `replace_file_content` 调用来增强该技能的描述。
- **模式识别**：如果你连续两次以上要求我执行相同的格式转换（如：按字母排序、特定 YAML 键值、特定目录结构），我必须将其沉淀为一个新的特定技能或更新到现有技能中。
- **知识库更新 (KI)**：主动请求后台系统将当前复杂任务的解决方案蒸馏为知识项，以便跨越对话周期保持记忆。

## 2. 进化日志规范

我会在 `.agent/logs/evolution_diary.md` 中维护一份简单的日志：

| 日期 | 触发事件 | 习得经验 | 改进动作 |
| :--- | :--- | :--- | :--- |
| YYYY-MM-DD | 用户纠正了 A-Z 排序 | 意识到用户对英语学习笔记有极高的整洁要求 | 更新了 english-word-parts 技能，增强排序权值 |

## 3. 用户反馈循环

- 每当我认为自己“进化”了（更新了技能或习得新模式），我必须在回复中告知用户并说明改进了什么。
- 欢迎用户通过命令 `/evolve` 来强制我进行一次深度自检。

## 4. 进化禁区

- 未经用户明确许可，不得修改已有的核心工作流或删除任何笔记。
- 进化动作应作为辅助步骤，不应干扰主任务的完成。
