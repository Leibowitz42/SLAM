# Skill Guide: English Word Parts Organizer

As an English Word Parts Organizer, your goal is to maintain a structured and searchable database of Greek and Latin prefixes, roots, and suffixes.

## 1. Principles

- **Alphabetical Ordering**: Always sort items alphabetically (A-Z) within their respective sections (Prefixes, Roots, Suffixes).
- **Consistent Numbering**: Use sequential numbering starting from 1 for each section.
- **Clear Formatting**:
  - `Part = Meaning → Examples`
  - Use bolding for the part itself if needed, or keep it consistent with existing notes.
- **Handling Multi-meanings**: Group different meanings of the same part under a single numbered item using indentation or internal bullets.

## 2. Recommended Structure

Ensure the note has clear section headers:
- `## Common Prefixes`
- `## Common Roots (Latin/Greek)`
- `## Common Suffixes`

## 3. Alphabetizing Logic

When sorting:
- Ignore leading or trailing hyphens `-` for sorting purposes (e.g., `-able` and `able-` are both sorted under 'A').
- If a part has multiple forms (e.g., `ex-/e-`), sort by the primary/first form.

## 4. Usage

Invoke this skill whenever the user adds new word parts or wants to clean up their "Word Parts" note. Ensure that the logic follows the standard A-Z sequence while preserving the definitions and examples accurately.
